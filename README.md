# 실시간 다국어 라이브 자막 및 통합 신경망 TTS 통역 서비스 (V0.4)

한국어(🇰🇷), 영어(🇺🇸), 베트남어(🇻🇳) 3개 국어 간 실시간 음성 인식, 쌍방향 라이브 번역 및 고음질 AI 신경망(Neural) TTS 통합 웹 애플리케이션입니다.  
Google Gemini 3.5 Live Translate API를 활용하여 음성을 인식하는 동시에 2개의 타겟 언어로 지연 없이 실시간 동시 번역하고 자연스러운 음성으로 출력합니다.

---

## 🌟 주요 기능 (V0.4)

- **2단계 문장 번역 제어 (2-Button Workflow)**:
  - `🚀 1. 번역 시작`: 세션 연결 및 음성 입출력 준비 상태로 진입
  - `🗣️ 2. 문장 번역`: 한 문장씩 말할 때마다 눌러서 인식 → 번역 → 고음질 TTS 자동 출력 후 안전하게 대기 복귀
  - 하울링 및 마이크 간섭 방지, 오작동 없는 깔끔한 통역 제어
- **실시간 번역 + AI 신경망 TTS 화면 통합**:
  - 기존 별도 페이지였던 고음질 Edge Neural TTS(한국어/영어/베트남어 자연스러운 아나운서 및 대화체 보이스)가 메인 통역 화면에 일체형으로 통합
  - 속도(Speed), 음높이(Pitch), 볼륨(Volume) 미세 조절 및 자동 읽기 / 다시듣기 지원
- **현문장 + 바로 직전 1문장 (총 2문장) 슬라이딩 집중 표시**:
  - 원문 및 번역문 패널 모두 **현문장 1개 + 바로 직전 문장 1개(총 2문장)**만 화면에 집중 표시되어 최상의 시인성 제공
  - 새로운 문장이 완성되면 가장 오래된 문장이 자동으로 교체
- **🖥️ 화면 최적화 (상단 전체 숨김 & 2부분/3부분 분할)**:
  - `[🖥️ 화면 최적화]` 버튼 클릭 시 상단 헤더, 언어 선택, TTS 세부 설정, 마이크 게이지 등을 모두 숨기고 **번역 화면만 크게 표시**
  - **3부분 표시**: 원문 + 번역 1 + 번역 2
  - **2부분 표시**: 원문 + 선택된 번역창 (상하 50:50 균등 분할)
  - `2분할` / `3분할` 프리셋 버튼으로 원클릭 전환 지원
- **3개 국어 상호 라이브 번역**:
  - `🇰🇷 한국어로 말하기`: 한국어 원문 발화 → 🇻🇳 베트남어 & 🇺🇸 영어 실시간 동시 번역
  - `🇺🇸 Speak in English`: 영어 원문 발화 → 🇻🇳 베트남어 & 🇰🇷 한국어 실시간 동시 번역
  - `🇻🇳 Nói Tiếng Việt`: 베트남어 원문 발화 → 🇺🇸 영어 & 🇰🇷 한국어 실시간 동시 번역
- **낮/밤 모드 테마 전환 및 전체 대화 기록 모달**:
  - 전체 누적 발화/번역 기록을 `📜 대화 기록` 팝업에서 언제든 확인 및 초기화 가능
- **🎧 청취자 전용 모드 (`/listener.html`)**:
  - 모바일이나 외부 태블릿에서 청취자 화면으로 접속하여 번역 자막 및 개별 TTS 청취 지원

## 🛠️ 기술 스택

- **Backend**: Node.js, Express
- **Frontend**: Vanilla HTML5, Modern CSS3 (Grid & Flexbox), Vanilla JavaScript (Web Audio API)
- **AI Model**: Google Gemini 3.5 Live Translate (`models/gemini-3.5-live-translate-preview`)
- **Protocol**: Bidirectional Streaming WebSocket (`BidiGenerateContent`)

## 🚀 시작하기

### 1. 사전 준비

- Node.js 20 이상
- Google Gemini API Key ([Google AI Studio](https://aistudio.google.com/)에서 발급)

### 2. 환경 설정

저장소를 클론한 후 프로젝트 루트에 `.env` 파일을 생성합니다:

```bash
cp .env.example .env
```

`.env` 파일에 발급받은 Gemini API 키를 입력합니다:

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
PORT=3000
```

### 3. 설치 및 실행

```bash
# 의존성 설치
npm install

# 서버 실행
npm start
```

브라우저에서 접속:
```text
http://localhost:3000
```

## 📖 사용 방법

1. 상단에서 **발화할 언어**(한국어 / English / Tiếng Việt) 버튼을 선택합니다.
2. 입력에 사용할 **마이크 장치**를 선택합니다 (USB 마이크 연결 시 자동 인식).
3. `🎤 번역 시작` 버튼을 누르고 브라우저 마이크 권한을 허용합니다.
4. 마이크에 대고 말하면 상단 2개 창에 번역문이, 하단 창에 원문이 실시간으로 표시됩니다.
5. 상단 우측 `📜 번역 기록` 버튼을 누르면 이전 발화 및 번역 이력을 언제든 확인할 수 있습니다.
